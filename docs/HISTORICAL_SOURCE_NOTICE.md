# Historical source notice

Earlier revisions of this repository experimented with design concepts and
adapted navigation vectors from
[Dime](https://github.com/rafsoh/dimeApp), a GPL-3.0 personal-finance project
created by Rafael Soh and contributors.

In September 2026, the adapted vectors were removed and the navigation moved to
standard Material iconography. Dime-prefixed internal component names and the
borrowed starter category palette were also replaced. The current tree keeps
this notice because the earlier revisions remain part of the public Git history.

aware continues to use GPL-3.0 as its open-source licence. This notice documents
project history; it is not a claim that the current app ships Dime artwork.
